# 📊 Chat Stats

Локальный плагин для **AyuGram / exteraGram**, который считает твою активность в чатах.

## ✨ Возможности

- 💬 Подсчёт отправленных текстовых сообщений
- 🔤 Подсчёт количества символов
- 📅 Статистика за сегодня
- 📆 Статистика за последние 7 дней
- 🗓 Статистика за последние 30 дней
- 📊 Просмотр всей сохранённой статистики
- 💾 Данные хранятся локально на устройстве
- 🔒 Статистика не отправляется на сервер

## 🛠 Команды

```text
.stats
.stat
.stats today
.stats week
.stats month
```

Команды перехватываются плагином и открывают удобное окно статистики.

## 📱 Совместимость

- **AyuGram / exteraGram:** 12.1.1+
- **Plugin ID:** `chat_stats`
- **Версия:** `1.3.3`

## 📦 Установка

1. Скачай файл [`chat_stats.plugin`](./chat_stats.plugin).
2. Открой его через AyuGram / exteraGram.
3. Установи плагин.
4. Отправь `.stats` в любом чате.

## 🔐 Приватность

Плагин не использует внешние серверы для хранения статистики. Данные сохраняются в локальном хранилище плагина на устройстве.

Для ограничения размера хранилища сохраняются последние **5000 сообщений на чат**.
